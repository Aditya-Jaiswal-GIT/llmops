# Groq LLMOps Platform

A modular LLMOps application built with:

- LangChain
- Groq
- FastAPI
- Tenacity
- Python logging

## Setup

1. Create a virtual environment.
2. Install requirements.
3. Configure the .env file.
4. Run the FastAPI server.

## Run

uvicorn app.main:app --reload
